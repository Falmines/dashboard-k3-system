==================================================
3. AUTHENTICATION
==================================================

Buat authentication menggunakan JWT.

Endpoint:
POST /api/auth/login

Request:
{
  "username": "admin",
  "password": "Admin123!"
}

Proses login:
1. Cari user berdasarkan username.
2. Pastikan status user = active.
3. Ambil password_hash dari PostgreSQL.
4. Bandingkan password menggunakan bcrypt.compare(password, user.password_hash).
5. Jangan membandingkan plain-text password.
6. Jika benar, generate JWT.
7. Jangan pernah mengembalikan password_hash ke frontend.

Response sukses:
{
  "success": true,
  "message": "Login berhasil",
  "token": "...",
  "user": {
    "id": 1,
    "name": "Administrator",
    "username": "admin",
    "email": "admin@example.com",
    "role_id": 1
  }
}

==================================================
11. PASSWORD HASH GENERATOR
==================================================

Tambahkan scripts/hash-password.js:

const bcrypt = require("bcrypt");

const password = "";

async function hashPassword() {
  if (!password) {
    console.log("Password belum diisi.");
    return;
  }

  try {
    const hash = await bcrypt.hash(password, 10);
    console.log("Hash:", hash);
  } catch (error) {
    console.error(error);
  }
}

hashPassword();

Tambahkan package.json:

"scripts": {
  "start": "node server.js",
  "dev": "nodemon server.js",
  "hash": "node scripts/hash-password.js"
}

Perintah:
npm install
npm run dev
npm run hash
